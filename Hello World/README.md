# Hello World

## Overview

This folder contains a basic Java "Hello, World!" program. It is a simple introductory program used to confirm that Java is installed and that a basic class with a `main` method can compile and run.

## Implementation

The program defines a `HelloWorld` class with a `main` method that prints `Hello, World!` to the console.

## Files

- `HelloWorld.java` - Java source file for the program.

## How to Run

```bash
javac HelloWorld.java
java HelloWorld
```

## Complexity

- Time complexity: O(1)
- Space complexity: O(1)

## Notes

This folder is not an algorithm challenge. It is a starter Java example.
