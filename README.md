# Algorithm Practice

This repository contains algorithm and data-structure practice solutions across several languages. It is intended to show ongoing problem-solving practice rather than a single flagship application.

## Current Problems

| Problem | Language | Notes |
| --- | --- | --- |
| Add Two Numbers | Python | Linked-list style arithmetic practice |
| Count and Say | C# | String generation practice |
| Integer to Roman | Python | Number conversion practice |
| Longest Substring Without Repeating Characters | PHP | Sliding-window style string practice |
| Median of Two Sorted Arrays | JavaScript | Array merge and median calculation |
| String to Integer | PHP | Parsing and validation practice |
| Sudoku Solver | Python | Backtracking practice |
| Two Sum | Java | Hash/map lookup practice |

## Repository Goals

- Keep each problem easy to identify.
- Include readable source code for each solution.
- Document the approach and complexity where practical.
- Avoid committing generated build files, binaries, or cache folders.

## Suggested Per-Problem Notes

For future additions, include:

- Problem summary
- Approach
- Time complexity
- Space complexity
- Example input and output
